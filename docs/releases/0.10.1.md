# 0.10.1 verification

Status: source verification complete. Publication and product installation are tracked separately. Product/runtime work is maintained outside this public repository.

## Scope and cause

`createSchemaResourceContext` constructed a fresh Ajv validator for each use. Native and response projections revisited equal declarations many times, including across newly cloned material contracts. Native output composition also called its schema-producing field helper while enumerating references. The fix preserves validated, immutable preparation by exact JSON content and separates reference selection from output-schema generation.

The fresh-context construction predates this patch (2026-10-10). Recursive resource preservation changed in 0.7.2 and native output composition was introduced in 0.8.0. This history identifies amplification paths; it does not establish a first failing version or attribute any particular external socket termination to this code.

## Verification

- New regression tests were run before the fix: identical cloned declarations compiled 24 distinct Ajv instances rather than 1; reference enumeration compiled 4 times rather than 0; resource immutability failed.
- After the fix, focused resource/preparation/composition tests: 23 passed.
- Full version-aligned source suite: 1,989/1,990 passed. The single failure is the previously known `prototype-looking JSON keys remain ordinary OAS data in runtime slot assignment` regression.
- Version-aligned type checks passed. Source lint, formatting and final documentation checks passed.
- Graph topology is generated from the actual LangGraph; graph-document regression: 5 passed. No new graph nodes or routing changes.
- Local n8n 2.37.10 native projection integration: six scenarios checked, including two intentional failures for invalid unselected data and a missing optional value. Four local HTTP requests in the successful nonempty cases; no business API/model calls.
- Local n8n native comparison integration: seven scenarios checked, with three successful flows and four expected failures (ambiguous multi-item input, invalid native contract, missing optional value and an assertion failure).
- An isolated private replay retained byte-identical model messages and output schema. Uninstrumented preparation was approximately 25.2 seconds before and 3.1 seconds after. Separate compile instrumentation counted 3,677 to 3 Ajv instances and 7,354 to 6 compilation calls. No private fixture or output is included here.
