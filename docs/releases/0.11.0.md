# 0.11.0 verification

Status: version-aligned source verification complete. Publication, public archive verification and product installation are tracked separately.

## Scope

The previous tracked planner fixed destinations before source selection. A container target could have no compatible original JSON source, yet force a provided-source answer. This release makes a source-backed construction plan the validation unit and leaves array/object descendants available without freezing a prior destination decision.

Core owns destination resolution, original-source membership, typed copying, assembly and final request/source checks. LangChain owns the model proposal contract. The example host owns bounded replanning and forwards only current-source, immediately preceding rejection feedback. No field-specific conversion, source reassignment or implicit value recovery is added.
