# 0.12.0 verification

Status at source freeze: source verification complete and release authorized on 2026-11-06. Source synchronization, tag, npm publication, public archive verification and GitHub Release are subsequent release steps, recorded separately from product installation and service deployment.

## Scope

The previous per-call protocol allowed the model to pair an otherwise correct literal with a message that did not contain it. The new workflow protocol removes independently generated message ownership and literal text. One code-owned source catalog supplies exact lexical references for every pending call, while OAS declaration templates supply destinations. Core derives values and provenance together and validates concrete targets and assembled requests.

The new LangChain function uses strict function-calling output and conservative target-type source choices. String destinations and string-array item destinations exclude numeric JSON references. Dynamic and recursive paths remain explicit symbolic templates, followed by the existing concrete OAS validation. The original single-call functions and example-host topology remain unchanged.

## Private live-model probe

The retained original six-call contexts were supplied to the new source consumer without executing Dev HTTP APIs or n8n. The final probe completed in 28.517 seconds with two shared literal-planning calls and one enum call. The first batch retained four calls and rejected two bulk calls whose selected `validationType` string did not satisfy the OAS. Only those two calls were replanned. Six final calls, five shared original inputs, exact values/types/message ownership and zero unresolved inputs passed independent assertions.

Two earlier protocol variants failed and were retained privately. The first used model-generated shared indices and selected numeric sources for string targets. A diagnostic confirmed that the original target contract accepted strings and rejected numbers; references had not been lost. The second typed-reference variant still returned forbidden numeric references without strict provider enforcement. The final protocol removes the generated index layer, supplies compatible source IDs consistently and requires strict function-calling output. A successful probe is evidence for this retained scenario, not a guarantee of semantic correctness.

The separate earlier full product attempt timed out in connection planning. This input-only probe did not exercise that stage and does not resolve its cause. No new browser recording, completed workflow, remote registration, remote execution or Cloud deployment is claimed.
