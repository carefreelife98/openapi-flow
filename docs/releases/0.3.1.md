# 0.3.1 release

Status: all three 0.3.1 packages published; exact public tarball bytes verified.

## Change

Fix the readiness mismatch between fixed-material connection planning and canonical
runtime input slots. A caller can explicitly defer exact current OAS-derived slot
IDs with `deferredApiInputIds`, keep the full API/native DAG, and export through
`compileN8nWorkflowTemplate`. No missing value is fabricated. Supplied values,
original contracts, current slot ownership, bindings, ports and topology remain
deterministically checked. Connection receipts capture the original deferral.

The legacy executable-fragment compiler does not accept this permission, because
it does not install canonical input/preflight nodes. API argument metadata cannot
replace the owning OAS during direct review validation. Native plan-time settings,
Webhook/callback scope and model retry policy are unchanged. See the
[input deferral guide](../deferred-connection-planning.md).

Keep `@openapi-flow/core`, `@openapi-flow/langchain` and `@openapi-flow/n8n` aligned
at 0.3.1. Required peers, runtime dependencies and Node.js 24 remain unchanged.

## Retained limitation

The previously accepted Ajv 8.20.0 `properties.__proto__` limitation remains. Its
original regression is enabled and failing, not skipped or reported as passed.
Original OAS/data are not rewritten. See the
[0.3.0 limitation](0.3.0.md#accepted-ajv-limitation). Any other deterministic failure
blocks publication; no numeric model-quality threshold is inferred.
