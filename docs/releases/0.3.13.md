# 0.3.13 release candidate

Status: version-aligned release gate completed; source synchronization and publication
are the next separate steps. The owner approved source-first synchronization, publication and exact
three-version installation exceptions on 2026-10-23. No 0.3.13 package has been
published at this stage. Product integration is separate from publication.

## Scope and ownership

Native edit target selection now receives code-derived source candidates already
available to value generation. One shared projection carries API/native identity,
API metadata, response declarations, pointer catalogs and actual preparation state.
New staged APIs remain visible before and after their request values are resolved.
The model selects actual IDs; it does not ask the user to supply internal IDs or
invent missing source contracts. Existing target/value output validation remains.

Connection edits now receive the optional entrypoint supplied by the host, with
the same ownership instructions as initial connection planning. Code derives roots
and the compiler owns the provided start behavior. When no entrypoint is supplied,
none is inferred. No output-schema permission to invent a trigger or start is added.

The registered response-object schema identifies its property names as local
workflow labels, not API request data or copied response values. Explicit user
labels are preserved; otherwise the model may choose unique concise labels from
the requested role and supplied API metadata. Response bodies, API values and
JSON types are not modified. No per-service mapping, fallback, silent retry or
model-output repair is added.

## Verified source behavior

Three missing-input regression assertions failed before the fix. The focused
native-edit/connection set then passed 22/22. The full pre-alignment suite passed
1,253 of 1,254 tests, with only the unchanged accepted Ajv special-key failure;
no tests were skipped or cancelled. Build, strict types, lint and formatting passed.

A bounded source-level run made five actual Chomsky calls, all HTTP 200, for
native target/value edits and connection planning. The resulting SDK template
contained five APIs, five aggregation fields and five numeric-zero assertions.
Existing native entries were preserved. This run explicitly prepared API steps;
it is not a full host conversation or execution in n8n. Earlier unsuccessful
attempts remain recorded separately.

## Separate host observations

A public 0.3.12 host conversation used two original OAS documents across four
natural-language turns. Three turns were approved. The fourth stopped on technical
questions about code-owned identities. All 26 model requests returned HTTP 200;
that transport result is not semantic success. Previous approved artifacts stayed
byte-identical while changes were pending. No business API was called.

The host source separately replaces raw edit-step instructions in the normal plan
overview with deterministic API/native/node labels derived from validated source
contracts. Original instructions remain debug material. Host checks passed 360
tests across 80 files, formatting, lint, strict types, production builds and
separate API/web test-source type checks. This source was not yet applied to the
running public-0.3.12 verification process. Its large initial JS chunk warning remains.

## Version-aligned release gate

The 2026-10-23 gate passed strict types/builds, lint and formatting. Unit results
were 1,253/1,254 with only the unchanged accepted Ajv failure and no skipped or
cancelled tests. All 54 original-OAS checks and all 18 isolated n8n suites passed.
Independent installation of the candidate packages passed strict public-type and
runtime consumption. npm audit reported zero known vulnerabilities. All three
archives passed metadata, exports, runtime-bundle inclusion, private-file exclusion
and SHA-512 verification. Only the eight intended workspace version values changed
in the lockfile; external dependencies and settings are unchanged.

The gate inspected a working candidate before its release source commit. Source
commit/push and a post-commit build/archive comparison must precede publication.
Publication, public download verification and host installation remain pending.
Only exact public 0.3.13 packages may be installed in the host under the approved
release-age exceptions. No private OAS, host source or credentials belong in this
public release.

The existing Ajv `properties.__proto__` limitation remains enabled and documented.
Original OAS and request data are not rewritten. General semantic quality, unseen
services, complete dynamic-target coverage and long-running streaming performance
are not established by the bounded checks above. Webhook/callback remain deferred.
