## Changes

See [scalable API binding planning](../scalable-api-binding-planning.md) and
[public release notes](0.3.15-notes.md). The compatible single-call planner remains;
the new public path scopes producer discovery and field planning to one target,
keeps every source discoverable, and assembles the whole plan with the original
coverage, pointer, type and global cycle validators. Call identities are code-owned.
Resource concurrency does not limit accepted OAS or selected API counts.

The owner supplies the LangChain model. Hosts may call each stage separately or
use bounded workers, cancellation and explicit same-input completed-call reuse.
No silent source pruning, field-name matching, data conversion, model-output
repair, hidden retry, timeout increase or new business API limit is introduced.
The shared per-call validator was extracted from the existing whole-plan validator;
the legacy validation messages/error codes and full-plan cycle checks remain.

probe passed one additional check, including JSON Schema 2020-12 meta-validation.

339 small model-fixture invocations. Eight actual Chomsky requests planned ten
bindings across five public-fixture API calls with no gaps or value conversion.

These are different cohorts, not a replay of a historical failed 170-call model

snapshots need not match that historical deployment.
