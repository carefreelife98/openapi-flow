# 0.3.2 release

Status: candidate verification complete within the scope below; not yet published.

## Change

Native and fixed-material connection planning now accept the existing optional
`WorkflowEntryPointContract` as `entrypoint`. A Manual Trigger host can supply
`describeN8nManualTrigger()` from the n8n adapter to both stages. Core validates
and snapshots that owner-provided contract; the model receives it as evidence,
not as an output field, selectable native capability or response producer.
`orchestrateWorkflow` forwards the same explicit contract and the Manual Trigger
reference composition supplies its compiler descriptor.

Omission does not infer a trigger. No reported gap is removed by matching its
text, no extra trigger is selected and no output, binding, dependency or DAG
check is bypassed. This patch does not implement Webhook/callback entrypoints.
Keep all three public packages aligned at 0.3.2. Peers and Node.js 24 requirements
remain unchanged.

## Verification and retained limitation

Seven new deterministic regressions cover input capture, message delivery,
source evidence, changed receipt rejection, omission, invalid boundary values,
output ownership and composition. The full unit result is 1148/1149: the original
Ajv 8.20.0 `properties.__proto__` regression remains enabled and failing under the
previously approved release limitation. It is not skipped or counted as passed.
See the [original limitation](0.3.0.md#accepted-ajv-limitation).

Strict workspace type checking, lint, format and source-derived graph checks
passed. Original private-service OAS checks passed 51/51. An initial invocation
pointed at a folder without the required ICL fixture and failed with `ENOENT`;
the corrected original-fixture directory passed without product changes.
Independent tarball installation passed with TypeScript strict and
`skipLibCheck: false`, no development dependencies or workspace symlinks.
Actual ChatOpenAI HTTP-wire tests verified entrypoint input and its absence from
generated output schemas. The isolated n8n request-binding matrix passed all
four cases and the deployment-template matrix passed. These are targeted patch
checks, not a fresh run of every historical integration matrix or a model
success-rate measurement. Host real-model DAG execution remains unverified.

Publication requires reviewed source commit/push and an exact matching remote
SHA first. Tarball verification, registry publication and host runtime validation
are separate steps; this record does not yet claim their completion.
