# 0.3.5 release

Status: owner-authorized release preparation. Source synchronization, publication,
public archive integrity and host installation are not yet complete. The current
verified public version remains 0.3.4. No tag or GitHub release is implied.

## Changes

Review questions may optionally supply their original single-/multiple-choice
contract. The model selects only current question/choice IDs and an enabled
reason. Core derives the display text, typed clarification reply and question
evidence from the same original contract. Changed identities, counts, duplicates,
derived text, replies and source snapshots fail explicitly without repair.

Unstructured questions and optional change/extension suggestions remain distinct.
An empty suggestion list is valid. Omitted choice contracts are not inferred from
labels or OAS citations. Explicit user adoption preserves the typed reply in its
receipt; generation and adoption do not submit an answer, approve a workflow or
select an API implicitly. The reference LangGraph passes original clarification
choices and retains the existing requirement-revision checks. A host still owns
its resume, review, replan and stop policy.

No service-specific branch, output sanitization, guessed field mapping, default
choice, schema coercion, hidden retry or extra model call is added. The three
packages and adapter Core dependencies are aligned at 0.3.5. The n8n adapter has
no implementation change; Node.js, Zod, LangChain and licensing are unchanged.

## Verification and limits

Final versioned regression passed 1170/1171 with only the
original owner-accepted Ajv failure, zero skipped and zero cancelled tests.
Original OAS-based checks passed 52/52. The independent packed consumer compiled
with strict TypeScript and `skipLibCheck: false`, used the full unchanged
34-operation catalog and exercised the new public choice schema/types/receipt.
The deterministic adoption conversation ran in isolated n8n 2.37.10 with two
actual HTTP calls to a synthetic local contract server. Typechecks, typed lint,
formatting, source-derived graph and documentation-link checks passed. Both the
pre-version and final versioned runs retained the same single original failure.
No release gate was relaxed for the new contracts.

Two independent actual-model calls reused the original clarification question,
three original choices and unchanged 34-operation private OAS from the previous
display failure. Explanations on/off each returned one typed choice proposal.
Code derived both displayed sentences without internal question/choice IDs and
left the input unchanged. These are two scoped observations, not general API
selection accuracy or host/browser validation. No suggestion was adopted, API
selected, workflow generated or business API/n8n executed in these actual-model
cases. Previous quality failures are preserved.

The separate host still uses public 0.3.4. New public installation, only the
three exact owner-approved release-age exceptions, typed review projection and
fresh actual-model/browser validation remain pending. A general recovery loop,
semantic API-selection quality and streaming/load work remain outside this patch.

## Retained limitation

Ajv 8.20.0 does not correctly validate a declared `properties.__proto__`.
Generated validation can reject valid data or omit that property's constraints.
The owner previously accepted this release limitation. Its original regression
remains enabled and failing, not skipped or counted as passed. No field rename,
value rewrite or compatibility schema transform is included. See the
[original limitation](0.3.0.md#accepted-ajv-limitation).
