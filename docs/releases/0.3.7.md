## Changes

- Add explicit `operation-multiple-choice` API questions with required minimum and
  maximum selection counts and an `operations` answer envelope.
- Preserve the original `operation-choice` / `operation` exactly-one contract.
  Never infer selection mode, counts or execution order from natural-language prose.
- Export synchronous `resolveApiOperationChoiceAnswer` and
  `validateApiSelectionQuestion` boundaries. Enforce bounds, distinct offered keys,
  matching question identity and answer shape without invoking a model.
- Extend model structured output and the host-owned LangGraph example. The complete
  catalog resolver retains current-snapshot validation and partial-answer behavior.
- Align all three public packages and internal dependencies at 0.3.7. No company
  source/OAS fixture, credential, guessed choice or local SDK substitution is added.
