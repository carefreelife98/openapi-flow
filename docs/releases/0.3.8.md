## Changes

- Add `N8nNativeFeature.ComposeApiResponses` and the public
  `createApiResponseObjectCapability` factory with exported input/parameter types.
- Let the model choose only explicit output names and existing API response
  references. Code derives value types from original OAS contracts and input ports
  from distinct sources in first-field occurrence order.
- Reuse official SDK Merge Append and Edit Fields (Set) builders, plus the existing
  full-response reader. A single source does not create an unnecessary Merge.
- Preserve scalar/null types, nesting, empty values, leading-zero strings and
  literal property names. Reject duplicate names, missing pointers, unknown
  sources and ambiguous source item counts without casting or value repair.
- Extend registered-feature planning, original-OAS regression, strict public-export
  consumption and the required isolated-n8n integration loop from 17 to 18 suites.

This capability composes one response item per API invocation. It does not add
native-output projection, per-item batch joins or arbitrary model-written code.
No company documents, credentials or host implementation enter the public package.
