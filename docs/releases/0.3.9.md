# 0.3.9 release

Status: authorized source-first release preparation; npm publication is pending
an unavailable security-audit endpoint. The owner approved publication of all
three packages and private-host exceptions for only their exact 0.3.9 versions.
Source synchronization, registry integrity and post-install host results are
separate steps and must not be inferred from the completed source checks.

## Changes

- Clarify shared edit instructions and proposal-schema descriptions so workflow
  behavior changes do not imply editing accepted requirement records themselves.
- Preserve explicit record revision, withdrawal and restoration, including their
  independent typed human answers and unchanged source/history validation.
- Treat unrequested optional OAS inputs as permitted omissions, not missing
  requirements. Requested unresolved inputs retain their original planning owner.
- Add wire-description and behavior-only planning regressions. No decision fields,
  runtime guards, API values, n8n node implementations or host orchestration change.

These changes guide semantic selection; they do not deterministically guarantee
every natural-language intent. No model-output filtering, automatic retry or
service-specific field matching is introduced.

## Verification boundary

Before manifest alignment, a one-stage actual-model probe reproduced unsolicited
record revision. Four post-change controls independently chose dependent API
addition, input-value editing, explicit record revision and explicit record
withdrawal. Each made one model call, with original outputs preserved. This probe
constructs a valid draft explicitly; it is not the original UI checkpoint or a
complete workflow-generation/browser result.

The source run passed 1,196/1,197 units with only the unchanged owner-accepted
Ajv 8.20.0 `properties.__proto__` limitation. Its original failing test remains
enabled. Focused 65 tests, typecheck, lint and format pass; a final 71-test group
includes all 54 original-OAS checks and actual graph/document/wire checks.
These pre-alignment checks do not replace the version-aligned release gate,
independent packed consumption, committed-source identity or registry verification.
The semantic probe does not execute a business service or establish complete
host/browser behavior. The version-aligned gate below separately checks the
existing n8n compilation/runtime contracts.

## Version-aligned source checks

The 0.3.9 gate completed typecheck, lint, formatting, all 54 original-OAS checks,
18 isolated local n8n suites, strict independent packed consumption and package
metadata/archive verification for all three packages. The independent consumer
installed 250 packages without workspace symlinks and made no model or business
API calls. Unit results remain 1,196/1,197, with only the unchanged, owner-accepted
Ajv failure and no skipped or cancelled tests.

The gate did **not** pass its security audit. Its npm audit child stalled and was
stopped after independent bounded requests confirmed endpoint timeouts. The
original report retains the failed/unfinished audit and `readyForOwnerReview:
false`; it is not rewritten to pass. A fresh audit after the owner's network
confirmation also timed out after 20 seconds, with system certificate trust and
zero fetch retries. Public package metadata returned HTTP 200, while even a
minimal audit-endpoint probe timed out. This isolates the observed failing
request, not the remote service's underlying cause or the current vulnerability
count. No TLS verification bypass or audit exemption has been applied.

Gate evidence is private in `.local-artifacts/release-candidate/0.3.9-5HIOPo/`;
the separate network recheck is in
`.local-artifacts/requirement-edit-boundary/audit-network-recheck-0.3.9.json`.
No external dependency version changed; internal package versions and the lockfile
are aligned. Publication and public-host installation remain pending. Existing
host servers and conversations remain on public 0.3.8.
