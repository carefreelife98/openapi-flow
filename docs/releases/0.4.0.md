## Scope

The candidate includes shared necessary-dependency/goal checks, initial and accepted
goal/material recovery, independent native selection review and explicit reselection
feedback, scoped revisable outlines and host-composable correction/checkpoint examples.

joins, native field projection and explicit count measurement, native-output
comparisons and native-value collection. Original OAS/runtime validation and linked

from automatic planning or a complete output-contract catalog for every n8n node.

## Preparation findings, 2026-10-27 KST

The first technical candidate completed initial strict type, lint and formatting
checks, then started the full enabled suite, original-OAS checks and isolated
loopback runtime suites. Its full output remains private. It predates the boundary
correction below and cannot serve as the final release-source check.

Source review and a direct runtime reproduction found that an edge-only model patch
caused code to label every reference-free disconnected node as a start, and every
unused placed output as a terminal. For a bundle containing only `first`, it added
boundaries for `first`, `second` and `third`. Core correctly rejected the unrelated
writes. Outside an outline, an empty model patch could place unrelated material.
The planner, not the final validation rule, owned this defect.

Three added regressions reproduced it before changing the implementation. The
correction restores explicit start/finish choices from actual supplied identities
and retains code-owned unique-port resolution. Both incremental and accepted-session
revision planners use the same endpoint resolver. The automatic-boundary helper is
removed; no special case for those node names, scenario matching or validation
exception is used. Post-fix schema, example checkpoint, wire, runtime and full
regression checks are recorded below. This is not private-host integration.
