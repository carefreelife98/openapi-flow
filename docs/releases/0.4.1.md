Status: preparation; not published.

annotated tag, npm packages and a published GitHub Release, followed by public local
Qoopilot installation. Company push, Cloud deployment and existing user-server restart
are excluded. This patch follows public 0.4.0 at `532a1f4` and includes source-bound
API material repair, existing-native dependency/parameter repair and explicit original
literal/enum message contexts. Library composition remains host-owned.

new context. Original OAS and runtime data are not rewritten.

## Verification

The first versioned candidate completed: 1,747/1,748 enabled tests with the known
Ajv failure, four original OAS documents/59 checks, strict types/build/Lint/format,
33 isolated runtime command suites, a strict packed consumer and three verified
archives. Its unchanged audit findings were High 5, Moderate/Critical 0. The original
automatic report remains blocked by that audit rather than being rewritten as clean.
This candidate predates the native-rejection changes below and cannot prove the
final source passed. Final candidate validation remains pending.

A fresh public-0.4.0 private-host comparison used the original five example documents
and OAS pairs, fresh providers/checkpoints and a single attempt per mode. Native
review was enabled in both modes; incremental hierarchical goal/outline review was
explicitly enabled. API selection matched all 28 expected kinds in each mode, but
neither mode reached connections or produced a workflow. There were four invalid
source quotations, one invalid native ownership/settings proposal, four unsupported
native outcomes and one legitimate business-question wait. Business API and engine
calls were zero. This is evidence against release-quality completion, not a reason
to suppress those checks or claim one connection strategy is better.

The subsequent correction adds explicit source-bound contract rejection feedback to
native selection/review and checkpoints it in the optional example-owned budgeted
loop. Source mutations retain their returned output but are not eligible for this
correction. Transport, cancellation, actual missing functionality and business
decisions are not converted to successful plans. Host integration remains pending.

A narrow actual-model source probe rejected an absent literal citation and succeeded
after one explicit example-owned correction. It used one fixed original Live API,
not API selection or a full workflow. There were no business API or n8n executions.
The final enum span was semantically weak; source validity is not meaning accuracy.
