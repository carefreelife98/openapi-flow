## Scope

This release preserves OAS contracts and executable checks while removing
presentation-only rejection conditions. It includes upstream business intent,
quote-free native/goal review, optional display metadata, registered
producer-determined settings and actual-call reservation settlement in the
host-owned consumer example. The importable planners still make individual calls;
Qoopilot owns conversation, stage order, checkpoints, budgets, progress and UI.

The current audit retains five High upstream dependency findings. Do not describe
this as clean.
Qoopilot installed the three public 0.4.2 packages after archive/release checks,
without substituting local archives. Initial intent and full-role-review wiring
passed 38 focused host tests. Whole-host verification then passed 120 files/652
tests, format, Lint, strict types, build and 16 HTTP routes. Under default file
parallelism, six tests timed out; a controlled four-worker full run passed without changing
deadlines or file isolation. The host now declares that test resource ceiling.
No existing user server was restarted.

documents, with clarification, upstream intent and full native role review enabled.
Automatic review and disabled follow-up suggestions were declared diagnostic
conditions. It produced SDK JSON with ten expected GET operations, three collectors,
one Merge and thirteen logical edges in 203.479 seconds. Eleven model HTTP requests
comprised ten 200s and one 429 handled by the existing routing policy. Reported usage
was 231,088 input and 9,316 output tokens from ten responses; unreported usage was
not estimated. No prior selection or connection materials were reused.

service groups and three final Merge items. All ten original response bodies and

or replaced to manufacture success. Fresh UI verification and the original-five
independent single-pass/incremental comparison remain unfinished. Quality thresholds
belong to the owner and are not inferred from test counts.
