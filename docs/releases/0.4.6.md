# 0.4.6 release

Published and locally adopted on 2026-10-28. Exact source commit
`428e499239385a72d980216a1a01a4fd11a81c00` was pushed to `origin/main` before
publication. The annotated `v0.4.6` points to that commit. All three public npm
versions and downloaded archives match the independently tested SHA-512 values.
The [GitHub Release](https://github.com/carefreelife98/openapi-flow/releases/tag/v0.4.6)
is published, with its notes, tag and target verified. No existing tag or npm
version was replaced.

## Problem and correction

After public 0.4.5 adoption, a fresh multi-service scenario selected ten APIs and
six native roles, then stopped at native parameter reference validation after
299.920 seconds. The gather runtime creates one result per selected source in
selection order, but its published output schema only describes an unordered
set. An independent planning-model replay correctly requested positional
information that the implementation had failed to declare.

The n8n adapter now emits `prefixItems` with exact provenance and original body
schemas. It retains the existing compiled reader, official Merge and Aggregate,
and original data. Core and LangChain have no execution-source changes in this
candidate. The independent installed consumer's explicit schema assertion is
updated to the same positional contract.

The host separately assigns semantic native configuration to its planning model.
Code-derived settings still acquire no model. This is a local host decision,
not a library policy or an extra native feature.

## Publication boundary and limitations

The current product installation is exact public 0.4.6. Every installed archive
file matches the public download: 1,152 Core, 444 LangChain and 434 n8n files.
Only the five intended manifest dependency values and three related Yarn lock
entries changed; unrelated lock entries remained byte-identical. Installation
scripts were disabled and the public scoped/corporate default registries kept.
Complete local verification passed in 152.80 seconds: 120 files/655 tests,
format, Lint, strict typecheck, production build and 16 API routes.

Public checks initially returned 404 for some new records/downloads after the
successful commands. Later canonical public downloads returned 200 and matched
the tested archives. The first n8n approval expired; the new approved command
succeeded. No successful package was republished to address the transient reads.

A fresh whole-scenario run has started with the same original text, separately
recorded delegated policy and OAS fingerprints, public packages only and a new
checkpoint. No previous model outputs or intermediate plans are injected.
Its outcome, engine/UI quality and original-five comparison remain unverified.
Company source push, Cloud deployment and existing user-server restart were
not performed. Published 0.4.5 and its source tag remain unchanged.

The previously disclosed Ajv special-key limitation and upstream High audit
warnings remain. Third-party dependencies are unchanged. This release does not
claim a clean audit or universally correct model interpretation.
