# 0.4.6 release candidate

Release and local product adoption authorized on 2026-10-28. The reviewed source
and version-aligned archives are prepared locally; source synchronization, tag,
npm publication, GitHub Release and product installation are not yet performed
for this version.

## Problem and correction

After public 0.4.5 adoption, a fresh multi-service scenario selected ten APIs and
six native roles, then stopped at native parameter reference validation after
299.920 seconds. The gather runtime creates one result per selected source in
selection order, but its published output schema only describes an unordered
set. An independent planning-model replay correctly requested positional
information that the implementation had failed to declare.

The n8n adapter now emits `prefixItems` with exact provenance and original body
schemas. It retains the existing compiled reader, official Merge and Aggregate,
and original data. Core and LangChain have no execution-source changes in this
candidate. The independent installed consumer's explicit schema assertion is
updated to the same positional contract.

The host separately assigns semantic native configuration to its planning model.
Code-derived settings still acquire no model. This is a local host decision,
not a library policy or an extra native feature.

## Evidence

- Focused contract/evaluation checks: 14 passed, including reversed selected
  order, wrong positional identity rejection and source-specific body projection.
- Enabled suite: 1,815 of 1,816 passed; only the previously accepted Ajv
  prototype-looking-key failure; zero skipped/cancelled tests.
- Original private OAS checks: 59 passed, with original documents unchanged.
- Isolated gather execution: five conditions, unchanged scalar, nested and empty
  values, repeated operation roles and single-source output, echoed unchanged.
- Actual-model stage replay: original selection and dependency proposals were
  revalidated against the corrected contract. Planning settings met three
  isolated engine conditions with ten reads, three authenticated calls, service
  groups of five/three/two and ten evaluations each.
- Another detail-model proposal passed technical checks but failed the empty-list
  business policy; it is not reported as a semantic success.
- Host local verification after model-purpose correction: 120 files/655 tests,
  format, Lint, strict typecheck, build and 16 generated API routes passed in
  141.46 seconds, while the product still installs public 0.4.5.
- Version-aligned candidate build, format and release/graph checks: passed;
  eleven release/graph tests. Three 0.4.6 archives installed without workspace
  links in an independent consumer and passed strict TypeScript with library
  checking enabled plus runtime SDK compilation.

The model replay uses fixed intermediate materials and a fixed downstream graph.
New full original-scenario generation, final JSON, isolated execution of that
JSON, UI and the five independent single/incremental pairs remain pending.

## Publication boundary and limitations

The current product installation is exact public 0.4.5. No local alias/archive
replaces it. Published 0.4.5 and its source tag remain immutable. This candidate
will follow the authorized source synchronization and release before product
adoption. Company source push, Cloud deployment and existing user-server
restart are outside the release scope.

The previously disclosed Ajv special-key limitation and upstream High audit
warnings remain. Third-party dependencies are unchanged. This candidate does not
claim a clean audit or universally correct model interpretation.
