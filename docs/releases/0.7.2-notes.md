# openapi-flow 0.7.2

This release preserves recursive static OpenAPI schemas as finite JSON resources.
Resolved runtime object cycles are converted to explicit `$ref` links and `$defs`
before operation contracts cross JSON boundaries. The original catalog snapshot
is retained. No fields, nulls or validation rules are removed or coerced.

API field, array-item and object-entry projections carry their schema resources.
Deep required-input checks follow the actual value path. Host validators and n8n
standalone validators register declared nested resources before their parents,
including resources shared by several API outputs under `prefixItems`. Runtime
pointer lookup uses a pure closed-resource resolver without a compiler or network.

Compatibility: existing planning wire formats are unchanged. Core adds the public
`listSchemaResources` utility and `SchemaResourceRegistration` type. Static schema
recursion is supported; relocating dynamic/recursive anchor scopes during static
bundling is explicitly rejected. Non-schema structural cycles and unresolved
references fail with their source. This is not a claim of complete OAS support.

Verification passed typecheck/build, lint, formatting, 54 checks against three
private OAS documents, an independently installed strict consumer, focused
recursive regressions, and four synthetic executions
in n8n 2.37.10 with two local reads each. A separate private, explicitly assembled
six-read workflow passed actual service response guards and three comparisons;
three in-memory price mutations each failed the comparison. These checks do not
claim fresh end-to-end model planning, product browser success or deployment.
The full suite passed 1928/1929; the existing Ajv `__proto__` slot-assignment
failure remains. The dependency audit still reports high 6 and moderate 11.
External dependency records are unchanged.
