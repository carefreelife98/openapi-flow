## Source changes

See [the contract guide](../connection-review-responsibility.md) and [public release notes](0.9.0-notes.md).

- An explicit, source-fingerprinted `declared-contract` boundary rejects free semantic goals in Core admission and the model wire schema. Original-requirement coverage remains a separate initial review. Legacy callers without this flag keep the separate semantic-review contract.
- Core checks exact call inventories, scalar settings, finite container shapes and graph obligations. Explicit unsupported goals retain limitation classification, original facts, grounds and affected nodes.
- Capability owners declare question and generated-text paths. Missing system contracts are technical errors, not questions asking users to invent producer references or schemas.
- Delivery inspection replays accepted state and preserves actual API inputs/bindings, native parameters, accepted wiring and diagnostics. Only closed, checked components are compiled; remaining components are nonexecuting design drafts.
- The n8n adapter owns actual API/native SDK output identities for delivery compilation. Hosts do not recreate node names or binding rules.
